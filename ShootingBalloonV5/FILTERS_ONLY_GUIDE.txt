? QUICK START (AUTOMATIC):
=============================================================================

1. Close Visual Studio completely
2. Run: APPLY_FILTERS_ONLY.bat
3. Reopen Visual Studio
4. Done! ?

=============================================================================
?? MANUAL STEPS (if automatic fails):
=============================================================================

STEP 1: Close Visual Studio
  - Save all files
  - File ? Exit

STEP 2: Run folder cleanup
  - Run: REMOVE_FOLDERS.bat
  - This moves all .asm files to Src\ folder
  - Removes empty physical folders

STEP 3: Update filters file
  - Delete: ShootingBalloonV5.vcxproj.filters
  - Rename: ShootingBalloonV5.vcxproj.filters.UPDATED
       to: ShootingBalloonV5.vcxproj.filters

STEP 4: Update project file paths
  - Run: UPDATE_PROJECT_PATHS.bat
  - This updates .vcxproj to point to new file locations

STEP 5: Reopen Visual Studio
  - Open ShootingBalloonV5.sln
  - Check Solution Explorer - you should see filters!

=============================================================================
?? TROUBLESHOOTING:
=============================================================================

PROBLEM: "Cannot find file" errors when building
SOLUTION: 
  - Check that all .asm files are in Src\ folder
  - Rebuild solution (Ctrl+Shift+B)

PROBLEM: Files appear in wrong filters
SOLUTION:
  - Manually drag files to correct filter in Solution Explorer
  - Visual Studio will update .vcxproj.filters automatically

PROBLEM: Physical folders still visible
SOLUTION:
  - Make sure you closed Visual Studio before running scripts
  - Delete physical folders manually from file explorer
  - Refresh Solution Explorer (F5)

PROBLEM: Include files not found during build
SOLUTION:
  - Verify Src\Include folder still exists
  - Check MASM Include Path in project properties:
    Project ? Properties ? Microsoft Macro Assembler ? General
    Include Paths = $(ProjectDir)Src\Include

=============================================================================
?? IMPORTANT NOTES:
=============================================================================

• Include folder (Src\Include) is KEPT as physical folder
  (needed for compiler to find .inc files)

• All other .asm files moved to flat Src\ folder

• Filters are VIRTUAL - they're just for organization in VS

• You can create/rename filters anytime in Visual Studio:
  Right-click filter ? Add ? New Filter

• Deleting a filter doesn't delete files (they remain in project)
