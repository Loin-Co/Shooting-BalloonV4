? TROUBLESHOOTING:
???????????????????????????????????????????????????????????????????????

  ERROR: "Cannot open file: common.inc"
  FIX: Set MASM Include Path:
       1. Right-click project ? Properties
       2. Microsoft Macro Assembler ? General
       3. Include Paths = $(ProjectDir)Src\Include
       4. Apply ? OK ? Rebuild

  ERROR: "Unresolved external symbol"
  FIX: UI files not added to project
       1. Check Solution Explorer for Src/UI/*.asm files
       2. If missing, use Add Existing Item
       3. Rebuild solution

  ERROR: Menu doesn't respond
  FIX: Check linker dependencies:
       1. Project Properties ? Linker ? Input
       2. Add: user32.lib kernel32.lib msvcrt.lib
