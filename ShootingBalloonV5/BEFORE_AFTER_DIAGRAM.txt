???????????????????????????????????????????????????????????????????????????
?                    KEY DIFFERENCE EXPLAINED                             ?
???????????????????????????????????????????????????????????????????????????

BEFORE:
  Folder = Physical directory on disk
  Visual Studio shows actual file system structure
  Moving file in VS = Moving file on disk

AFTER:
  Filter = Virtual organization (metadata)
  Physical files in flat Src\ folder
  Moving file in VS = Just updating filter metadata
  No actual file movement on disk!
