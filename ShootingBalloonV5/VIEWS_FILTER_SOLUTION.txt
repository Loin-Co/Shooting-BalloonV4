?? WHY THIS HAPPENED:
=============================================================================

  The .vcxproj.filters file was missing:
  
  1. Views filter definition
  2. Filter assignments for the 4 UI files
  
  The files existed physically in Src\Views\ but weren't assigned to
  a filter in Visual Studio, so they appeared at the project root.

=============================================================================
?? TECHNICAL DETAILS:
=============================================================================

  What gets added to .vcxproj.filters:

  1. Filter Definition:
     <Filter Include="Views">
       <UniqueIdentifier>{F4G4J1H6-7I8J-9J2F-EH3G-6I9J1K2G3H4I}</UniqueIdentifier>
     </Filter>

  2. File Assignments:
     <MASM Include="Src\Views\loading_screen.asm">
       <Filter>Views</Filter>
     </MASM>
     (and same for menu, level_select, instructions)
