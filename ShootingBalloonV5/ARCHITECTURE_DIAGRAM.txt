? MEMORY LAYOUT
???????????????????????????????????????????????????????????????????????

g_ConsoleBuffer:
  ????????????????????????????????????????????????????????
  ? [0]   [1]   [2]   ...   [79]    ? Row 0 (80 cells)  ?
  ? [80]  [81]  [82]  ...   [159]   ? Row 1              ?
  ? ...                                                   ?
  ? [1920][1921] ...  [1999]        ? Row 24 (last row) ?
  ????????????????????????????????????????????????????????
  
  Each cell = CHAR_INFO (4 bytes):
    WORD UnicodeChar  (2 bytes) - Character to display
    WORD Attributes   (2 bytes) - Color (foreground + background)

Total size: 2000 cells × 4 bytes = 8000 bytes (8 KB)

? COLOR SYSTEM
???????????????????????????????????????????????????????????????????????

Theme Color          Value   Usage
??????????????????   ?????   ?????????????????????????????????
THEME_BG             0x00    Black background
THEME_BORDER         0x0C    Light red (neon border)
THEME_TEXT_MAIN      0x07    Light gray (standard text)
THEME_TEXT_ACCENT    0x0E    Yellow (highlights, scores)
THEME_WARNING        0x04    Dark red (warnings)
THEME_BTN_HOVER      0x4F    White on red (menu selection)

Color byte format: [Background << 4 | Foreground]
  Example: 0x0C = 0x00 (black bg) | 0x0C (light red fg)

? ANIMATION SYSTEM
???????????????????????????????????????????????????????????????????????

Loading Screen Animation:
  1. Draw border                     (instant)
  2. Display header                  (instant)
  3. Show welcome text               (instant)
  4. Initialize progress bar         (instant)
  5. FOR each system (4 systems):
       - Display system name         (instant)
       - Sleep 400ms                 (delay)
       - Display status              (instant)
       - Update progress +25%        (instant)
       - Sleep 300ms                 (delay)
  6. Animate progress bar:
       FOR i = 0 to 60:
         - Draw bar segment          (instant)
         - Update percentage         (instant)
         - Sleep 15-35ms             (delay based on i)
  7. Final hold                      (Sleep 1200ms)
  8. Transition to menu              (instant)

Total time: ~3 seconds
