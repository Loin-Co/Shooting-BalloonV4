?? MANAGING FILTERS IN VISUAL STUDIO:
???????????????????????????????????????????????????????????????????????????

CREATE NEW FILTER:
  Right-click project ? Add ? New Filter ? Enter name

RENAME FILTER:
  Right-click filter ? Rename ? Enter new name

MOVE FILE TO FILTER:
  Drag file from one filter to another in Solution Explorer

DELETE FILTER:
  Right-click filter ? Remove
  (Files remain in project, just not organized)

ADD FILE TO FILTER:
  Right-click filter ? Add ? Existing Item ? Select file

? TROUBLESHOOTING:
???????????????????????????????????????????????????????????????????????????

PROBLEM: Build errors "cannot find file"
FIX: Rebuild solution (Ctrl+Shift+B)

PROBLEM: Files in wrong filters  
FIX: Drag files to correct filter in Solution Explorer

PROBLEM: Physical folders still exist
FIX: Close VS, manually delete folders, reopen VS

PROBLEM: Include files not found
FIX: Check Src\Include folder exists and contains .inc files
     Verify MASM Include Path = $(ProjectDir)Src\Include
