```

     ?
???????????????????????????
? User presses W or S     ? ? Move selection up/down
? User presses ENTER      ? ? Start level (if unlocked)

???????????????????????????
```

## Example Interaction Sequence

1. **Main Menu**: User selects "START GAME" ? Transitions to Level Select
2. **Level Select**: Screen shows:
   - Levels 1-3: Unlocked with stars
   - Levels 4-6: Locked
   - Current selection: Level 1 (highlighted)

3. **Navigation**:
   - Press S ? Selection moves to Level 2
   - Press S ? Selection moves to Level 3
   - Press W ? Selection moves back to Level 2

4. **Selection**:
   - Press ENTER on Level 2 ? Starts Level 2 gameplay
   - Press ENTER on Level 4 (locked) ? Nothing happens
   - Press ESC ? Returns to Main Menu

## Difficulty Indicators in Level Names

```
Easy    ? Green/Yellow theme (approachable)
Medium  ? Orange theme (moderate challenge)
Hard    ? Red theme (difficult)
Expert  ? Purple/White theme (master level)
```

## Best Score Display Format

```
BEST: 450  ? 3 digits, right-aligned, yellow color
BEST: 1280 ? 4 digits, right-aligned, yellow color
BEST: 0    ? Never played or no score recorded
```

## Footer Controls Reference

```
???????????????????????????????????????????????????????????????
?     [W/S]: Navigate   [ENTER]: Play   [ESC]: Back           ?
???????????????????????????????????????????????????????????????

W      = Move selection UP (decrements selectedLevel)
S      = Move selection DOWN (increments selectedLevel)
ENTER  = Confirm selection and start level (if unlocked)
ESC    = Cancel and return to main menu
```

## Implementation Details

### Star Rendering (Using ASCII Blocks)
```asm
Filled Star: db 219, 0    ; ? (solid block)
Empty Star:  db 176, 0    ; ? (light shade)
```

### Level Number Display
```
Format: "X. LEVEL_NAME (Difficulty)"
Example: "1. THE BARRENS (Easy)"
         "6. IT'S LAIR (Expert)"
```

### Spacing and Alignment
```
Row spacing: 3 lines per level entry
   Line 1: Level info and stats
   Line 2: (optional separator)
   Line 3: Empty space
```
